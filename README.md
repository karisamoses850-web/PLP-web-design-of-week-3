# Budget Tracker - Visual Design Challenge

A polished, user-friendly personal budget tracker built using HTML5 and modern CSS3.

## Features & Enhancements
- **Cohesive Color Palette:** Utilizes a professional color scheme featuring deep slate blue headers and emerald green accent buttons.
- **Custom Typography:** Integrated Google Fonts (`Poppins` for distinct headings and `Inter` for clean body readability).
- **Card-Based Layout:** Leveraged the CSS Box Model (`margin`, `padding`, `border-radius`, and subtle `box-shadow`) to turn the header, form, and table into distinct, clean visual cards.
- **Interactive Tables & Forms:** Enhanced forms with focus states and styled tables with alternating row colors and distinct table headers.

## File Structure
- `index.html`: Contains the core structure of the budget tracker.
- `style.css`: Contains all visual styling, layout rules, and box-model definitions.
- `README.md`: Project documentation.
